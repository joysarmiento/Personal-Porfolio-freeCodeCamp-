Introduction to HTML

HTML (HyperText Markup Language) is the foundation of every webpage on the internet. It defines the structure of content and provides meaning to text, images, and multimedia elements.

Unlike programming languages, HTML is a markup language. It doesn’t perform logic or calculations, but instead tells browsers what each piece of content represents.

An HTML document is made of nested elements that describe headings, paragraphs, links, images, and other content. These elements are enclosed in tags, such as <p> for paragraphs.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <p>Hello, World!</p>
</body>
</html>
  • HTML provides the structure of web pages
  • It works alongside CSS (for styling) and JavaScript (for interactivity)
  • Browsers interpret HTML to render websites
HTML Elements

An HTML element is the basic building block of a webpage. It consists of an opening tag, optional content, and a closing tag. Some elements, such as images, are self-closing.

Here’s the general structure of an element:

<tagname>Content goes here</tagname>

Some examples:

<p>This is a paragraph.</p>
<h1>This is a main heading</h1>
<a href="https://example.com">A hyperlink</a>
  • Paragraphs: <p> represent blocks of text
  • Headings: <h1> to <h6> represent titles, with <h1> as the most important
  • Links: <a> create clickable hyperlinks
  • Images: <img> embed pictures
  • Lists: <ul>, <ol>, and <li> create lists

Some elements are block-level (taking full width, like <div> and <p>) while others are inline (taking only as much width as needed, like <span> and <a>).

HTML Attributes

Attributes provide extra information about elements. They always appear in the opening tag and are written as name-value pairs.

For example, the href attribute specifies the destination of a link:

<a href="https://example.com">Visit Example</a>

Here are some common attributes:

  • href: Specifies the link destination in <a> tags
  • src: Defines the source of an image or video
  • alt: Provides alternative text for images, useful for accessibility
  • id: Assigns a unique identifier to an element
  • class: Groups elements for styling with CSS

Example with multiple attributes:

<img src="cat.jpg" alt="A cute cat" width="300" height="200">
HTML Forms

Forms allow users to submit data to a server. They are essential for user interactions such as logging in, signing up, or submitting feedback.

A simple form example:

<form action="/submit" method="post">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name">

  <label for="email">Email:</label>
  <input type="email" id="email" name="email">

  <input type="submit" value="Submit">
</form>

Common form elements include:

  • <input>: text fields, checkboxes, radio buttons
  • <label>: associates text with input fields
  • <textarea>: allows multi-line input
  • <select>: creates dropdown menus
  • <button>: clickable buttons

Forms also support validation through attributes like required, maxlength, and pattern.

Semantic HTML

Semantic HTML uses tags that clearly describe their meaning. This makes web pages easier to understand for both developers and machines (like search engines and assistive technologies).

For example, instead of using <div> everywhere, semantic HTML provides elements like <header>, <article>, and <footer> to give context.

<header>
  <h1>My Blog</h1>
</header>
<main>
  <article>
    <h2>First Post</h2>
    <p>This is my first blog post.</p>
  </article>
</main>
<footer>
  <p>© 2025 My Blog</p>
</footer>
  • <header>: Represents introductory content, often a logo or navigation
  • <nav>: Defines a block of navigation links
  • <main>: Contains the dominant content of the page
  • <article>: Represents self-contained content like a blog post
  • <footer>: Holds information about the author, copyright, or related links

Semantic HTML improves accessibility for screen readers, boosts SEO rankings, and makes code easier to maintain.
